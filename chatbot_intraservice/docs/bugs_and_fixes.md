# Чатбот IntraService: баги и исправления

Журнал заметных инцидентов, ложных срабатываний, принятых исправлений и **идей развития** (backlog).
Формат: **дата → симптом → причина → исправление → заявка**.

Обновление: `python scripts/publish_bugs_confluence.py` · исходник: `docs/bugs_and_fixes.md`.

## Как читать таблицу

| Колонка | Смысл |
|---|---|
| **Дата** | Когда обнаружили / зафиксировали |
| **Область** | watch / analyze / learn / UI / n8n / docs |
| **Симптом** | Что увидел оператор или заявитель |
| **Причина** | Корневая логика / настройка |
| **Исправление** | Что изменили (или статус backlog) |
| **HD** | Номер заявки-примера (если есть) |
| **Автор** | Кто предложил / выявил (если известен) |

## 2026-09-02 — шум 400 на `iek/confluence-agent` (снят с LiteLLM)

| | |
|---|---|
| **Область** | LLM / `watch_new` / `analyze_and_comment` |
| **Симптом** | Каждые 3–5 мин HTTP 400 `Invalid model name … iek/confluence-agent` на стороне ДИТ (Попцов) |
| **Причина** | Агент `iek/confluence-agent` снят с прокси; в `.env` остался `IEK_LLM_SUPPORT_MODEL=iek/confluence-agent`. Prefetch Confluence — **REST** (`confluence_tools.py`), не LLM. Бот всё равно слал первый запрос на мёртвую модель, потом fallback |
| **Исправление** | `llm_client.resolve_model()` + дефолт `iek/gpt-oss-120b`; обновлён `.env`. Поиск KB: REST prefetch + corpus |
| **HD** | — |
| **Автор выявления** | Попцов (ДИТ) |
