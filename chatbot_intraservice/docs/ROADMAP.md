# Roadmap — итерации chatbot_intraservice

Источник видения ДИТ: презентация *«ИИ в поддержке 2026 v2»*.

**Где мы сейчас:** этап **применения чатбота в IntraService** — бот уже работает с заявками HelpDesk (разбор для исполнителя, watch, AI-KB из закрытых).

**Куда идём:** тот же контур знаний, но **чатбот, встречающий пользователей** (сотрудник пишет до/вместо «просто создать заявку»): ответ из KB или заявка с правильным сервисом, описанием и скриншотами.

В деке это ближе к связке **L1-консультант + снижение диспетчеризации**, без слова «L0». У нас в docs **L0** = встречающий чат; **L1 HD** = текущий IntraService-бот для исполнителя.

## Принцип итераций (vibe-coding)

1. Одна итерация = одна спека в `docs/specs/` + измеримый smoke.
2. Не начинать L0, пока L1 HD стабилен на watch + AI-KB ревью в Streamlit.
3. После итерации — строка в `docs/handoff.md` и при необходимости пункт в `AGENTS.md` Known pitfalls.

## Iteration 1 — L1 HD стабильность

**Цель:** исполнитель получает один полезный скрытый разбор; нет антипетель.

| Критерий | Как проверить |
|----------|----------------|
| Watch_new / overdue / user_reply | scheduler + dry-run |
| Вложения PDF/DOC/скрин | `test_attachments_extract` + заявка с файлами |
| AI-KB: reject с причиной → учёт в learn | Streamlit + `test_learn_llm` |
| Learn на `confluence-agent` | `call_history` / analysis.model |

Документы: `docs/pipeline/решения.md`, `docs/pipeline/самообучение.md`.

## Iteration 2 — AI-KB качество

**Цель:** черновики пригодны к Promote; мусор (типа HD-09) отклоняется и не размножается.

- Формат corpus: симптом / не путать / проверка / ответ (не сырой Q&A).
- Дайджесты gap / drafts.
- Опционально: кластеризация rejected (backlog IDEA §6).

---

## Iteration 3 — L0 чат сотрудника (MVP)

**Спека:** [`specs/L0_employee_chatbot.md`](specs/L0_employee_chatbot.md).

**Цель MVP:** сотрудник пишет проблему → ответ из KB **или** заявка в правильном ServiceId с описанием + вложениями.

Переиспользовать: `service_routing`, corpus, `attachments` (если юзер шлёт скрин), IntraService create task (см. `docs/интеграции/`), матрицу уточнений в `docs/prompts/`.

**Не в MVP:** полная замена диспетчера, CRM L2, AutoFAQ cloud.

## Связь «сейчас / потом»

| Актив L1 HD | Зачем L0 |
|-------------|----------|
| corpus + AI-KB | ответы сотруднику |
| service_routing + ServiceId | выбор сервиса заявки |
| attachments / OCR | скрины в заявке |
| learn from closed | улучшение KB после эскалаций |
| analyze_and_comment | **не** UX сотрудника; остаётся для исполнителей |
