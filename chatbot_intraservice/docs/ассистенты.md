# Ассистенты чатбота IntraService (1 линия)



## Open WebUI vs API



| Имя в chatgpt.iek.local | В `GET /v1/models` | Роль |

|:--|:--|:--|

| `support-dep-lk-web-helper` | **нет** (только UI) | Внутренний WEB / HelpDesk. **Не меняем** карточку. |

| `partner-lk-web-helper` | **нет** (только UI) | Партнёр ЛК. Не для заявок IntraService. |
| `support-dep-bp-web-helper` | **нет** (создать вручную) | БП / ЦКГ. См. `docs/openwebui_bp_1c_helpers.md` |
| `support-dep-1c-web-helper` | **нет** (создать вручную) | 1С: резерв в пути, заказы. См. тот же doc |

| — | `iek/confluence-agent` | Поиск по Confluence WEBKB через API |

| — | `iek/confluence-agent-crm` | Confluence CRM (узкий контур) |

| — | `iek/qwen3.5-122b-vl-int4` / `iek/gpt-oss-120b` | Общий LLM + наши промпты L1 |



Шлюз бота ходит в `https://llm.iek.local/v1`. Имена `*-web-helper` из URL Open WebUI **нельзя** передать как `model` в chat/completions.



## Маршрутизация



| Профиль | Когда | Модель | База |

|:--|:--|:--|:--|

| **`bp_tickets`** | bp.iek.ru / ЦКГ / ServiceId=833 | `IEK_LLM_BP_MODEL` | `knowledge/bp` · UI `support-dep-bp-web-helper` |
| **`onec_tickets`** | заказ/счёт/резерв в пути / 1С | `IEK_LLM_1C_MODEL` | `knowledge/1c` · UI `support-dep-1c-web-helper` |
| `l1_web` | ЛК, КП, WEB (не БП) | `IEK_LLM_SUPPORT_MODEL` | WEBKB + промпты L1 |

| `l1_crm` | CRM | `iek/confluence-agent-crm` | Confluence CRM |

| `partner_howto` | how-to ЛК без HD | partner model | P-00…P-17 |



Корпус БП собрать/обновить:



```powershell

python scripts/build_bp_corpus.py

```



Источники: pageId 124629661, 124629493 + до 50 закрытых заявок ServiceId=833 (email/телефон/ИНН маскируются).



Проверка регистрации: `https://adm.bp.iek.ru/main?search=<email>&page=1&pageSize=16`  
API: `/api/user/v1/profiles?search=...`

Cookies (из браузера Application → Cookies adm.bp):  
`BP_ADM_COOKIE=kc-access=...; kc-state=...; kc-refresh=...`

Авто-refresh kc-access: `POST /api/auth/v1/refresh` (за 120 с до exp) → `.env` + `.bp_adm_session.json`.

```powershell
python scripts/refresh_bp_adm.py
python scripts/test_bp_adm.py
```
