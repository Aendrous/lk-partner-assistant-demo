# Как вставлять схемы в Confluence (WEBKB)

## Решение: **draw.io Board Diagram** (`drawio-sketch`)

| Макрос | Когда | Вердикт |
|:--|:--|:--|
| **draw.io Board Diagram** | Flowchart чатбота, маршруты уточнений, правки мышкой | **Выбран** |
| Mermaid Diagrams for Confluence | Только код → картинка, без ручной вёрстки | Опционально |
| BPMN Modeler Enterprise | Формальный BPMN 2.0 с пулами/дорожками | Избыточен для L1 |
| Сырой `<pre>flowchart TD` | Публикация скриптом «как текст» | **Не использовать** |

Почему Board: на `confluence.dev.iek.ru` уже много draw.io; на странице чатбота макрос `drawio-sketch` уже стоит; в Board есть **Insert → Mermaid…** — вставляете код из репозитория и получаете редактируемую схему.

## Как обновить схему на странице

1. Открыть [Чатбот ИИЭК: схема 1 линии…](https://confluence.dev.iek.ru/pages/viewpage.action?pageId=124630073) → Edit.
2. Клик по Board → открыть редактор.
3. `+` → **Mermaid…** → вставить код из `схемы/mermaid_для_drawio_board.mmd` (или блок Mermaid на странице в expand).
4. При необходимости подправить узлы → Save → Publish.

Либо: заменить/дополнить диаграмму «Схема ИИЭК бота» / «ИИ диаграмма доп вопросов».

## Что делает скрипт публикации

`scripts/publish_chatbot_bpmn_confluence.py`:
- **сохраняет** существующие макросы `drawio` / `drawio-sketch`;
- обновляет таблицы матрицы и текст;
- кладёт актуальный Mermaid в expand **«Исходник Mermaid для Board»** (для копипаста);
- **не** вставляет сырой flowchart в `<pre>`.

## Mermaid plugin vs Board

- **Board + Mermaid import** — один раз импорт, дальше удобно двигать блоки (рекомендуем).
- **Mermaid Diagrams** — схема всегда = код; удобно для API, хуже для «подрихтовать стрелку».

Источник истины по логике: `схемы/bpmn_чатбот_l1.md` + `prompts/матрица_уточнений.md`. FigJam — параллельный визуал для воркшопов.
