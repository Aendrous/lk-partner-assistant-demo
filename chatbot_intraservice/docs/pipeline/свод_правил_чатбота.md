# Свод правил: чатбот IntraService (1 линия HelpDesk)

**Confluence:** https://confluence.dev.iek.ru/x/ONttBw  
**Папка:** `chatbot_intraservice/`  
**ИИ:** корпоративный `llm.iek.local` / UI https://chatgpt.iek.local/?model=support-dep-lk-web-helper

## Функция

Ассистент **исполнителя** HelpDesk: скрытый разбор заявки + черновик ответа. Не чат для внешнего партнёра.

## Куда нужен

Ветки ЛК (731/732), БП (833/827), смежные сервисы WEB. Ускорить 1 линию: факты, проверки, KB, без подмены человека.

## Правила поведения

1. Скрытый комментарий «Разбор от чатбота IEK LLM» — исполнителю, не клиенту.
2. Уже «В процессе» / «Ожидание ответа» при take → skip.
3. Дубли по заказу/счёту/GUID → ParentId + наблюдатель.
4. Просрочка «До просрочки» → take + скрытый; открытый ответ заявителю только при KB.
5. «Спасибо / заработало» от заявителя → статус **120** + публичный комментарий; уточнение / «не помогло» → **38**; без скрытого разбора.
6. AI-KB: только после ревью человека в Confluence.
7. API каталога ЛК (`mailer@iek.ru`) ≠ API-ключ bp.iek.ru.

## Streamlit

**Не обязателен.** Панель оператора (настройки, ручной прогон, история), порт 8502.
Движок = CLI + Task Scheduler. Опция: `install_scheduler.ps1 -WithStreamlit`.

```powershell
cd chatbot_intraservice
streamlit run app.py --server.port 8502
```

- Локально: http://localhost:8502  
- LAN (типичный ноутбук в корпсети): http://10.1.25.17:8502 (IP смотреть в `ipconfig` / Network URL Streamlit)  
- Демо/dev, не публичный интернет; прод — сервер в корпсети, порт 8502 за reverse proxy.

## Вложения

- `extract-msg` — точнее Outlook; без пакета — OLE-fallback.

## Прод

Сервер во внутренней сети + venv + `.env` + планировщик (watch_new / user_reply / overdue / learn). Streamlit опционально за proxy.

## Установка (кратко)

```powershell
pip install -r requirements.txt
pip install -r chatbot_intraservice\requirements.txt   # + extract-msg
cd chatbot_intraservice
copy .env.example .env
powershell -File scripts\install_scheduler.ps1
```
