## Зачем

Когда исполнитель **закрыл заявку**, а в KB **не было готового ответа**, чатбот:

1. Сравнивает свой скрытый разбор и публичный ответ человека (`learn_compare.py`, IEK LLM).
2. Ищет похожую статью — локальный корпус, черновики, CQL Confluence WEBKB (`kb_dedup.py`, `confluence_client.py`).
3. IEK LLM решает: новая статья / дополнение / пропуск (`kb_gap_llm.py`).
4. Создаёт черновик с блоком `KB_INSERT` → ревью в Confluence (`ai-kb-draft`) → Promote в «Быстрые ответы».

Человек **всегда** правит текст перед Promote. В боевую KB попадает только маркер `<!-- KB_INSERT_START/END -->`.

Глоссарий терминов (Promote, PII, supplement): [`глоссарий_ai_kb.md`](глоссарий_ai_kb.md) · Confluence после `publish_ai_kb_glossary_confluence.py`.

**Контур CRM:** отдельный корпус Q&A — [`самообучение_crm.md`](самообучение_crm.md) · WEBKB [pageId 124642008](https://confluence.dev.iek.ru/pages/viewpage.action?pageId=124642008).
