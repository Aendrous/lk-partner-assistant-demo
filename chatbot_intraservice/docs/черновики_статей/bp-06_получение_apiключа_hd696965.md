## BP-06. Доступ к API
**Сценарий:** Доступ к API
**Ключевые слова:** личный кабинет, ЛК.
**Проверка исполнителя:**
1. Учесть факт: Вход в API теперь требует API‑ключ, который должен быть получен из личного кабинета.
2. Учесть факт: В личном кабинете пользователь не нашёл способ получить API‑ключ.
3. Учесть факт: Пользователь просит предоставить ссылку или помочь с получением ключа.
**Из решения исполнителя:**
- Клиент часто путает lk.iek.ru (ЛК партнёра) и bp.iek.ru (БП/API). Ключ API товаров — на bp, не в ЛК.
- API-ключ БП: https://bp.iek.ru/profile#api-keys (username=ticket, password=ключ)
- Вижу, что вы не нашли способ получить API-ключ для доступа к информации о товарах. Похоже, возникла путаница между личным кабинетом партнёра (lk.iek.ru) и бизнес-платформой (bp.iek.ru): API-ключ для доступа к каталогу выдаётся именно на bp.iek.ru.
- Как получить ключ:
- 1. Войдите на https://bp.iek.ru под своей учётной записью ().
- 2. Откройте профиль → раздел «API-ключи»: https://bp.iek.ru/profile#api-keys
_Источник: BP-06._

**Сценарий:** Тендер T260902-192450 «зависает» и не переходит в статус согласования в CRM.
**Ключевые слова:** тендер, согласование, CRM, статус, принудительный перевод.
**Не путать с:** доступ к API (BP-06).
**Проверка исполнителя:**
1. Откройте карточку тендера в CRM.
2. Убедитесь, что у вас есть роль «Ответственный за тендер» или права «Переводить в согласование».
3. Нажмите кнопку «Перевести в согласование». Если статус не меняется, откройте консоль разработчика → Network и проверьте запрос `POST /api/v2/tenders/{id}/status`.
4. Если запрос возвращает 403 – недостаточно прав, передайте тендер ответственному за согласование или обратитесь в админку → Тендеры → Управление правами.
5. При отсутствии ошибки, выполните принудительный переход через админку: `GET /admin/tenders/{id}/force-approve` (доступно только администраторам).
6. После изменения статуса проверьте, что в истории появилось событие «Переведено в согласование».

**Сценарий:** Пользователь‑региональный представитель не может открыть тендер в CRM, получает сообщение «Недостаточно привилегий». 
**Ключевые слова:** CRM, тендер, доступ, привилегии, региональный представитель, согласование. 
**Не путать с:** доступ к API (BP‑06). 
**Проверка исполнителя:**
1. Убедиться, что пользователь вошёл в CRM под своей учётной записью.

3. Если пользователь не ответственный, запросить у текущего ответственного (например, Максимова А.) предоставить общий доступ к тендеру.
4. При необходимости доступа ко всем тендерам в своей ФО/МФО оформить согласование у руководителя РФО (Ярослав Чуприн).
5. После получения согласования администратор CRM добавит пользователя в группу «Тендеры – региональный представитель» через настройки прав (Настройки → Управление ролями → Тендеры).
6. Проверить, что после обновления прав пользователь видит тендер без ошибки.
