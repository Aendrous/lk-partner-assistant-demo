## CRM-26. Перевод статуса тендера в «Условия согласованы»
*Источник: HD#701350 · https://helpdesk.iek.local/Task/View/701350*  
**Ключевые слова:** статус, согласование, тендер, Условия согласованы, пересчёт тендера  
**Не путать с:** статус «В работе», статус «Закрыт»
### Разновидность A — список согласующих заполнен
**Сценарий:** все согласующие отметили «согласовано», но статус остался «Согласование условий».  
1. Откройте карточку тендера.  
2. Проверьте список согласующих – все должны иметь отметку **«согласовано»**.  
3. В меню **«Статус»** выберите **«Условия согласованы»**.  
4. Сохраните изменения.  
5. Добавьте комментарий: *«Статус переведён после подтверждения всех согласующих»*.
### Разновидность B — список согласующих пустой (тендер не был рассчитан)
**Открытый ответ:** только после проверки, без «ожидайте обновление».  
1. Перейдите в раздел **Тендер → Расчёт**.  
2. Нажмите **«Пересчитать»** и дождитесь завершения расчёта.  
3. После пересчёта откройте карточку тендера – список согласующих должен появиться.  
4. Выполните шаги из **Разновидности A**.  
*Готово.*
