## CRM-18. Выгрузка email‑адресов прямых партнёров с активными коммерческими условиями  
*Источник: HD#700634 · https://helpdesk.iek.local/Task/View/700634*  
**Ключевые слова:** email, прямые партнёры, активные коммерческие условия, выгрузка, рассылка  
**Не путать с:** выгрузка данных в 1С, выгрузка по «Честному знаку»  
### Разновидность A — Стандартная выгрузка (Excel)  
**Сценарий:** Предоставить список email‑адресов в файле Excel, один адрес – одна строка.  
1. Откройте CRM РФ → раздел **«Партнёры»**.  
2. Установите фильтры: **Тип партнёра = прямой** и **Коммерческие условия = активные**.  
3. Нажмите **«Выгрузить» → Excel (XLSX)**.  
4. Проверьте, что колонка **Email** заполнена полностью.  
5. Прикрепите файл к ответу, укажите срок доставки (обычно ≤ 1 рабочий день).  
### Разновидность B — Выгрузка через API (опционально)  
**Открытый ответ:** Предложите использовать API‑метод  
```
GET /api/partners?type=direct&commercialStatus=active&fields=email
```  
и уточните, нужен ли автоматический экспорт или интеграция.
