## BP-05. Проверить, зарегистрирован ли клиент в БП (adm)

**Проблема / контекст:** зависает регистрация на bp.iek.ru; клиент «не может войти»; непонятно, создалась ли учётка.

**Проверка (исполнитель):**

1. Открыть админку:  
   `https://adm.bp.iek.ru/main?search=<email>&page=1&pageSize=16`  
   (можно искать по телефону / ИНН, если email нет).
2. Результат в скрытый комментарий одной строкой:  
   `adm: найден / не найден · <url>`.
3. Если учётка есть, а вход не работает — дальше по симптомам (пароль / незавершённая регистрация / ЭДО).  
   Если нет — регистрация не завершилась; смотреть логи/ошибки формы, не обещать «уже есть кабинет».

**Варианты формулировок:** не могу зарегистрироваться bp; зависает сохранить и войти; проверить регистрацию в админке БП.

**Связь:** шаблоны API БП — pageId=124629493; эскалация DBP — Перепелкин А.В.
