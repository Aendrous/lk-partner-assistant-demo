## HD-06. запрос отчета по рассылке Profi
**Сценарий:** запрос отчета по рассылке Profi
**Ключевые слова:** личный кабинет, ЛК.
**Проверка исполнителя:**
1. Учесть факт: Рассылка проведена 24 июля для участников клуба Profi
2. Учесть факт: Запросить количество получателей, процент открытия и другие метрики
3. Учесть факт: Email партнёра не указан
**Из решения исполнителя:**
- Исполнитель должен быть Агабальянц Геворг.
- Разрабатывать ничего не надо.
- 24 июля была рассылка для электромонтажников. Тема: эксклюзивно для участников IEK PROFI — скидка 20% на IEK в «Дом Лента»

- Особенно интересуют:
- уникальные пользователи
