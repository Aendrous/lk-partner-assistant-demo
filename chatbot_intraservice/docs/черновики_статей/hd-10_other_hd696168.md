## HD-700893. Блокировка аккаунта IEK ID
**Сценарий:** Пользователь сообщает, что его аккаунт IEK ID заблокирован, недоступны кнопки «Настроить интегрированные системы» и «Настроить двухфакторную авторизацию».
**Ключевые слова:** блокировка аккаунта, интеграции, 2FA, IEK ID, профиль.
**Не путать с:** обычной проблемой авторизации (неправильный пароль, отсутствие подтверждения почты).
**Проверка исполнителя:**
1. Открыть админскую панель `adm.bp` и попытаться выполнить поиск пользователя по IEK ID. Если запрос возвращает *«требуется авторизация, аккаунт не найден»* – аккаунт действительно заблокирован.
2. В системе ЛК (`lk-admin`) выполнить поиск того же пользователя. Отсутствие записи подтверждает блокировку.
3. При подтверждении блокировки создать задачу в Jira (тип *«Разблокировка аккаунта»*) автоматически из статуса HelpDesk «На разработку».
4. После закрытия задачи проверить, что кнопки «Настроить интегрированные системы» и «Настроить двухфакторную авторизацию» стали активными в профиле `iekid-profile.iek.ru`.
5. При необходимости выполнить сброс 2FA через внутренний сервис поддержки (см. статья «Сброс 2FA»).
**Открытый ответ (шаблон):**
> Ваш аккаунт был временно заблокирован
