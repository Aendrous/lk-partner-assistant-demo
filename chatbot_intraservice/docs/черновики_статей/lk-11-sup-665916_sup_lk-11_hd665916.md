## LK-11‑SUP‑665916. Настройка маркера «Цена по запросу» для проектных артикулов в API каталога
*Источник: HD#665916 · https://helpdesk.iek.local/Task/View/665916*  
**Ключевые слова:** API, цена по запросу, проектные артикулы, PriceIndividualPre, PriceIndividualPost, null‑значения  
**Не путать с:** обычными ценами (price, saleprice), которые задаются в прайс‑листах  
### Разновидность A — Проектные артикулы без цены в API
**Сценарий:** Партнёр получает `null` в полях `price`, `saleprice`, `PriceIndividualPre`, `PriceIndividualPost` и др. для артикулов‑проекта (например, MPOR‑002‑1‑04). Требуется, чтобы в ответе API возвращалось значение «Цена по запросу».  
1. Откройте **Администрирование → Товары**.  
2. Найдите нужный артикул (по коду) и откройте его карточку.  
3. На вкладке **«Ценообразование»** включите флаг **«Цена по запросу»** (обычно — чек‑бокс *Price on request*).  
4. Сохраните изменения.  
5. Перейдите в **«Настройки → API каталога»** → **«Маршруты → Products»** и убедитесь, что в списке `entity` присутствует `PriceIndividualPre,PriceIndividualPost,rrc,roc`.  
6. Выполните **очистку кеша**: `System → Cache → Очистить → API‑Cache`.  
7. Проверьте результат запросом, например:  
   ```
   https://lk.iek.ru/api/products?format=jsonp&art=MPOR-002-1-04&entity=PriceIndividualPre,PriceIndividualPost,rrc,roc
   ```  
   Поля `price`, `saleprice`, `PriceIndividualPre`, `PriceIndividualPost` должны содержать строку **«Цена по запросу»** (или `null` → `"Price on request"` в зависимости от формата).  
8. Сообщите партнёру, что цены теперь отображаются как «Цена по запросу».  
### Разновидность B — Проверка наличия артикулов в прайс‑листах (опционально)
**Открытый ответ:** После включения маркера проверьте, что артикул действительно отсутствует в активных прайс‑листах (раздел **«Прайс‑листы → Товары»**). Если артикул присутствует, отключите его из прайс‑листа или пометьте как «Не использовать в API», иначе маркер не будет применён.  
*Только после выполнения вышеуказанных шагов отправляйте ответ заявителю.*
