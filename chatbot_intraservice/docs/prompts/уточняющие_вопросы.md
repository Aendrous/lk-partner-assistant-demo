# Уточняющие вопросы (перед заявкой)

Полная матрица: [матрица_уточнений.md](./матрица_уточнений.md)

## Алгоритм цикла

1. **Шаг 0 (роутинг)** — если контур неясен: особенно **lk.iek.ru vs bp.iek.ru** при «ЛК / API / ключ / заказы».
2. Определи **категорию** (AUTH, ORDERS, API_LK, API_BP…).
3. Пройди **шаги 1→2→(3*)** только для этой категории; за шаг 1–3 вопроса.
4. Не дублируй ответы из чата. Стоп — когда поля из сводной таблицы заполнены.

## Сводка: сколько шагов

| Сервис | Категории | Шагов | Вопросов |
|:--|:--|:--:|:--:|
| Роутинг | ROUTING | 1 | 1 |
| КП (corp.iek.ru) | AUTH, ACCESS, SMS_2FA, OTHER | 2 | 2–4 |
| ЛК (lk.iek.ru) | AUTH, ORDERS, NS_RESERVE, API_LK, DOCS_UPD, OTHER | 2–3 | 2–5 |
| bp.iek.ru / ЦКГ | AUTH_KEY, API_BP, OTHER | 2–3 | 2–5 |
| VPN / диски | CONNECT, DISKS | 2 | 3–4 |
| Почта | DELIVERY, ACCESS | 2 | 2–4 |
| Прочее | GENERIC | 2 | 2–3 |

## Критичный роутинг (пример)

```
Вы про ЛК/API — уточните контур:
• lk.iek.ru — Личный кабинет партнёра (заказы, НС, API каталога)
• bp.iek.ru — Бизнес-платформа / ЦКГ (ключи, API ЦКГ)
```
