Политика конфиденциальности

Приложение «Помощник партнёра ЛК» (package com.aendrous.lkpartnerassistant) — демо-чат справки по личному кабинету партнёра IEK.

Какие данные обрабатываются

  • Текст вашего вопроса и история сообщений в текущей сессии на устройстве.
  • Вопрос вместе с фрагментами встроенных инструкций отправляется в сервис GigaChat (ПАО Сбербанк) для генерации ответа.

Приложение не запрашивает логин/пароль lk.iek.ru, не читает контакты, геолокацию и файлы телефона, не показывает рекламу и не проводит оплату.

Оператор и поддержка

Пилотная сборка. Технические сбои личного кабинета IEK: hd@iek.ru.

Ключ API

В демо-сборке может использоваться личный ключ GigaChat (scope PERS, Freemium). Для промышленной версии IEK ключ должен храниться корпоративно (scope CORP) и не публиковаться в git.
